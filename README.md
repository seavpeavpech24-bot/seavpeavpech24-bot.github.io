# Portfolio Website - SEAVPEAV PECH

A modern, responsive portfolio website showcasing my projects and skills as a Junior Full Stack Developer.

![Portfolio Preview](assets/images/profile.jpg)

## Features

- **Responsive Design**: Fully responsive layout that works on mobile, tablet, and desktop devices
- **Project Gallery**: Showcase of various projects with detailed information
- **GitHub Pages Compatible**: Optimized for hosting on GitHub Pages
- **Modern UI**: Clean, professional design with animations and visual effects
- **Interactive Elements**: Modal image galleries, smooth scrolling, and more

## Technologies Used

- HTML5
- CSS3 (with Tailwind CSS)
- JavaScript (Vanilla JS)
- Font Awesome Icons
- Responsive Design Principles

## Installation and Usage

1. Clone the repository:
   ```
   git clone https://github.com/yourusername/portfolio.git
   ```

2. Open the project folder:
   ```
   cd portfolio
   ```

3. Open `index.html` in your browser to view the website locally.

## Project Structure

```
portfolio/
├── index.html              # Main portfolio page
├── project-details.html    # Project details page
├── assets/                 # Assets directory
│   ├── images/             # Project and profile images
│   └── videos/             # Video content (if any)
└── README.md               # This file
```

## Deployment

This portfolio is designed to be easily deployed to GitHub Pages:

1. Create a GitHub repository for your portfolio
2. Push your code to the repository
3. Enable GitHub Pages in the repository settings
4. Your portfolio will be available at `https://yourusername.github.io/portfolio/`
